# 02. Управление проектами с помощью Cargo

### Примеры задания зависимостей в соответствии с SemVer

| Оператор | Пример | Минимальная версия | Максимальная версия | Обновление |
| :--- | :--- | :--- | :--- | :--- |
| Карет | `^2.3.4` | `>=2.3.4` | `<3.0.0` | Разрешено |
| Карет | `^2.3` | `>=2.3.0` | `<3.0.0` | Разрешено |
| Карет | `^0.2.3` | `>=0.2.3` | `<0.3.0` | Разрешено |
| Карет | `^2` | `>=2.0.0` | `<3.0.0` | Разрешено |
| Тильда | `~2.3.4` | `>=2.3.4` | `<2.4.0` | Разрешено |
| Тильда | `~2.3` | `>=2.3.0` | `<2.4.0` | Разрешено |
| Тильда | `~0.2` | `>=0.2.0` | `<0.3` | Разрешено |
| Джокер | `2.3.*` | `>=2.3.0` | `<2.4.0` | Разрешено |
| Джокер | `2.*` | `>=2.0.0` | `<3.0.0` | Разрешено |
| Джокер | `*` | Не определена | Не определена | Разрешено |
| Сравнение | `=2.3.4` | `=2.3.4` | `=2.3.4` | Не разрешено |
| Сравнение | `>=2.3.4` | `>=2.3.4` | Не определена | Разрешено |
| Сравнение | `>=2.3.4,<3.0.0` | `>=2.3.4` | `<3.0.0` | Разрешено |
