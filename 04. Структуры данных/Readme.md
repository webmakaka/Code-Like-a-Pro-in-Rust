# 04. Структуры данных

### 01. Строковые типы

| Тип | Разновидность | Компоненты | Использование |
| :--- | :--- | :--- | :--- |
| `str` | Динамически разгруженный строковый слайс (в чистом виде в стеке не размещается, используется через указатели) | Последовательность байт в формате UTF-8 | Базовый строковый тип, на который создаются ссылки; напрямую в переменных без указателя не используется |
| `String` | Размещаемая в куче строка в формате UTF-8 | Вектор байт (`Vec<u8>`) | Изменяемая строка с возможностью изменения размера и выделения и высвобождения памяти по мере необходимости |
| `&str` | Ссылка на неизменяемую строку (строковый слайс) | Указатель на массив байт в куче, стеке или статической памяти, дополненный длиной строки в байтах | Может использоваться везде, где требуется неизменяемое заимствование либо `str`, либо `String` |
| `&'static str` | Ссылка на неизменяемую статическую строку | Указатель на объект `str` в статической памяти, дополненный его длиной в байтах | Ссылка на `str` с явно указанным временем жизни `static` (хранится в скомпилированном бинарнике) |

### 02. Слайсы и массивы

Мас­сив является последовательностью значений фиксированной длины, а слайс - по­следовательностью значений произвольной длины.
То есть слайс может иметь переменную длину, определяемую во время выполнения, а массив имеет фиксиро­ ванную длину, известную во время компиляции.
